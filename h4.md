## F) Nora crackme02

Käänsin ohjelman binääriksi ja laitoin sen ghidraan.  
Menin ghidrassa taas automaattisesti main funktioon katselemaan.  

<img width="406" height="572" alt="image" src="https://github.com/user-attachments/assets/5db0becc-c6a8-47d9-b22f-2515fd759de2" />  

main funktiosta löytyy kyllä salasana "password1" mutta se ei toimi.  
Päätin mennä jatkamaan main funktiota  
Main funktion muuttujien nimet voivat olla:
- param_1 = argc
- param_2 = argv
- pcVar1 = input
- cVar2 = reference_char
- uVar3 = exit_status
- pcVar4 = input_ptr
- pcVar5 = reference_ptr

Ohjelma aloittaa tarkistamalla että on annettu yksi argumentti oman nimen lisäksi.  
seuraavaksi määrittää muuttujat ````input```` ```reference_char``` ```exit_status``` ```input_ptr``` ```reference_ptr ```

Alussa ohjelma tarkistaa ehdolla `argc == 2`, että argumentteja on kaksi. Ohjelman oma nimi lasketaan mukaan, joten sen lisäksi pitää antaa yksi argumentti eli kokeiltava salasana. Jos määrä on väärä, ohjelma tulostaa `"Need exactly one argument."`.

Seuraavaksi katsoin kohtaa, missä näkyi merkkijono `"password1"`. Tämä ei kuitenkaan sellaisenaan ole oikea salasana, sillä tarkistuksessa oli seuraava ehto:

```c
if (reference_char + -1 != (int)*input_ptr)
```

Tässä vertailumerkin ASCII-arvosta vähennetään yksi ja tulosta verrataan käyttäjän antamaan merkkiin. `*input_ptr` tarkoittaa osoittimen kohdalla olevan merkin lukemista. Jos merkit eivät täsmää, ohjelma ilmoittaa salasanan olevan väärin ja lopettaa palautusarvolla `1`.  
Ensimmäinen vertailumerkki on `p`, jonka ASCII-arvo on 112. Kun tästä vähentää yhden, saadaan 111 eli `o`. Seuraavana on `a`, jonka arvosta 97 saadaan vähentämällä 96 eli backtick-merkki.  
Tässä ei siis vain siirrytä aakkosissa taaksepäin, vaan katsotaan ASCII-arvoltaan yhtä pienempi merkki.  
Silmukassa `reference_ptr` siirtyy yhden merkin eteenpäin jo ennen vertailua. Tämä ei kuitenkaan ohita ensimmäistä merkkiä, koska `reference_char` sisältää aluksi merkin `p`. 
Onnistuneen vertailun jälkeen siihen luetaan seuraava vertailumerkki ja myös `input_ptr` siirtyy eteenpäin. `input` jää osoittamaan syötteen alkuun, jotta ohjelma voi tulostaa koko annetun salasanan.  
Kun saman vähennyksen tekee kaikille `"password1"`-merkkijonon merkeille, salasanaksi muodostuu:

```text
o`rrvnqc0
```
Testataas vielä onko salasana oikein.

Ja oinkeinhan se on!
