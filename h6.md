# h6 Onkohan tämä turvallinen käyttää?

Aloitin tehtävän lataamalla moodlesta tiedostot sekä githubista komennolla ``` git clone https://github.com/robbins/tp-link-decrypt.git```  
Vein nämä kaikkin omaan hakemistoon jotta pysyisivät jotenkin hallussa.  

<img width="919" height="139" alt="Screenshot 2026-10-06 200323" src="https://github.com/user-attachments/assets/460eec17-0705-48ba-9518-da7f555b2862" />  

Siirryin kansioon ``` tp-link-decrypt``` ja ajoin komennon ``` ./preinstall.sh```.  
Perään ajoin vielä ```./extract_keys.sh```.  
Nyt pitäisi alkaa purkamaan ohjelmaa.  
Ajoin komennon ```make``` mutta tuli vain virhe joka oletettavasti tarkoittaa jonkun ohjelman tai muun puuttumista.  

<img width="974" height="255" alt="image" src="https://github.com/user-attachments/assets/e4b6d6a7-0067-42cc-b961-dfbc58b2f36d" />  

Hetken etsimisen jälkeen löysin puuttuvan olevan ```libssl-dev``` jonka asennuksen jälkeen ```make``` toimii.  

<img width="1865" height="98" alt="image" src="https://github.com/user-attachments/assets/0398a908-0126-426a-b731-97b6b7fdd5a9" />  

Komennolla ```./bin/tp-link-decrypt Tapo_C200v4_en_1.4.2.bin``` löysin key/iv mutta eipä näistä mitään hyötyä ollut...  

<img width="513" height="296" alt="image" src="https://github.com/user-attachments/assets/95093583-4add-49cf-90e8-c6b85723f673" />

Päätin toista tapaa ja extractasin suoraan dumppi tiedoston mikä ladattiin alussa komennolla ```binwalk -e dump-tapo-c200v3-1.4.2.bin``` joka loi uuden hakemiston missä oli ```suqashfs-root``` hakemisto.

Jotain hienoja sanoja sai mutta eipä mitään millä saisi avattua mitään.  
Löytyi kummiskin kohtia jotka liittyvät admin-salasanan muuttamiseen, käyttäjätileihin, P2P-salasanan sekä AES-avaimen hakemiseen, eipä niillä tässä tee mitään mutta voisi joku parempi käyttää hyökkäykseen.  
Tässä kohtaa minulla loppui taidoit ja jäin kokonaan jumiin.  
En usko että salasana olisi kovinkaan heikko.
